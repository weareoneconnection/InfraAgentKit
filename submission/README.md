# InfraAgentKit——交通基础设施全生命周期受治理多智能体框架

第二届“交融杯”人工智能场景创新应用大赛 · 开源项目赛道 · V3.0 参赛提交版

## 提交文件

1. `final/` 下的设计报告 DOCX 与同版 PDF（按大赛对应赛道报告模板框架编制）。
2. `01_五分钟演示脚本与分镜.md`
3. `02_开源与数据边界.md`
4. `03_评测说明.md`
5. `04_授权脱敏样例与专家验证记录模板.md`：真实数据授权与专家签字模板，未签署时不得作为真实验证证据。
6. `final/video/InfraAgentKit-线上实机演示.mp4`：22.64 秒线上实机操作录屏，可按五分钟分镜脚本补录旁白。
7. `final/InfraAgentKit_提交包.zip`：上述文件、演示视频与源代码包（`源代码/InfraAgentKit-V3.0.zip`，由 Git 导出的干净代码）。
8. `final/SHA256SUMS.txt`：逐文件校验值。

在线演示：<https://infraagentkit-production.up.railway.app>。V3.0 内置 30 个受治理智能体（24 个专业域、4 个控制域、2 个独立核验域），按任务动态选择不超过 5 个专业智能体，并叠加控制与核验平面；同时提供 10 个工具、57 条双语合成知识来源和 54 项可复现评测。生产演示环境已挂载独立持久化数据卷；大模型增强只有在部署环境同时配置模型地址、模型名和密钥后才启用，未配置时使用确定性规则与证据契约。

## 仍需人工完成

- 按演示脚本为已生成的线上实机录屏补录讲解旁白（如大赛要求旁白）。
- 在报名表中填写团队成员与单位信息，完成单位审批。
- 在大赛平台对应赛道提交，并保存提交回执。
- 提供一份经授权的脱敏样例或由行业专家签署的验证记录；未取得授权前不得用真实项目材料替代合成数据。

所有项目、构件、资料、照片和评测数据均为合成数据。
