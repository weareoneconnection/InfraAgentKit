# InfraAgentKit 五分钟演示脚本与分镜

赛道：开源项目。目标时长 4 分 30 秒，不超过 5 分钟；旁白按每秒约 4 个汉字核算。

主线：五分钟装好 → 30 个智能体覆盖 24 个工程域 → 一张卡片定义边界 → 按任务动态组队 → 证据路由、只读取证、跨智能体交接与合成 → 副作用只是待审批意图 → 未批准执行被拒绝 → 具名人员批准后执行、8 项核验 → MCP 接入 → 基准与开源规范。

## 录制准备

- 终端：`pip install -r requirements.txt && pip install -e .`；浏览器打开 `infra-agent serve --port 8103` 后的 `http://127.0.0.1:8103`。
- 画面 1920×1080；终端字体放大；分段录制、剪辑合成。

| 0:08–0:35 | 痛点 | 文字卡：“依据某规范”（编造）、“不要乱发邮件”（提示词）、“已完成”（自称） | 智能体进入施工安全、质量、合同这些高责任场景，难点不是能不能回答，而是结论有没有依据、谁授权它动手、动手以后能不能证明。 |
| 0:35–1:00 | 安装与智能体目录 | 终端：`infra-agent doctor`（30 个智能体、24 个专业域、10 个工具、57 条知识、MCP SDK 可用）；控制台筛选专业域、控制域和核验域 | 安装后一条命令检查环境。30 个智能体不是同时争抢任务，而是由卡片声明能力、数据边界、协作关系与升级路径。 |
| 1:00–1:45 | 动态组队与证据契约 | 运行“高处作业同时影响进度与索赔……”→ HSE 主智能体、专业支持与 4 个控制智能体动态组队；展示交接、证据引用和合成结论 | 系统按任务选择主责和协同专业，并自动加入编排、数据接入、证据溯源和独立核验。分析阶段只能调用只读工具；结论只能引用本次真实检索到的来源。 |
| 1:45–2:35 | 人工关卡与核验 | 副作用动作 AWAITING_APPROVAL；点“执行（未批准会被拒绝）”→ 已拒绝；审批人“项目经理 张工”批准 → 执行 → 草稿 DRAFT_ONLY_NOT_SENT，核验 8 项全部通过 | 起草停工指令是写操作，只能生成待审批意图。没批准就执行，直接拒绝。具名人员批准后，运行时按提出时的卡片复核策略，只执行被批准的原参数，再由独立核验器做八项检查。 |
| 2:35–3:00 | 对抗输入 | 点样例“干扰：无证据”（I have no knowledge of this site…）→ GAP，无动作 | 这句话里的“knowledge”包含“edge”，简单的字符串匹配会误判成高处作业。框架按词边界匹配，没有证据就是证据缺口，不提出任何动作。 |
| 3:00–3:30 | 账本防篡改 | 终端：`infra-agent audit` → valid；用 sqlite 修改一条审批记录后再运行 → valid false、broken_at | 每一步都写入哈希链账本。有人事后改了一条审批记录，校验立刻失败，并指出第一处断裂的位置。 |
| 3:30–3:55 | MCP | 终端：`infra-agent mcp-serve`；用 MCP 客户端列出 8 个工具并调用 `catalog_coverage` 与 `knowledge_search` | 同一套能力通过官方 MCP SDK 提供给任何 MCP 宿主。宿主可以发现 24 个专业域、检索、运行智能体、查看待审批事项，但批准和执行刻意不开放。 |
| 3:55–4:20 | 基准与开源 | 终端：`infra-agent eval` → 54 项 PASSED（11 项治理攻击）；`pytest -q` → 42 项 PASSED；展示 README、SPEC、LICENSE、CI | 评测既覆盖 24 个专业域，也包含提示词注入、编造引用、自我批准、重复执行、卡片篡改等十一项治理攻击，全部通过。规范、示例、测试和持续集成一并开源。 |
| 4:20–4:30 | 片尾 | 片尾卡 | 让交通行业的每一个智能体都有依据、有边界、可证明。InfraAgentKit。 |

## 故障预案

| 风险 | 处理 |
| --- | --- |
| MCP 包未安装 | `pip install "mcp>=2,<3"`，或只演示控制台与命令行 |
| 账本篡改演示需改数据库 | 使用 `sqlite3 data/infraagentkit.db "UPDATE ledger SET actor='x' WHERE kind='action.approved'"`，演示后删除数据库 |

## 录制前检查

- 画面中无密钥、真实项目或人员信息。
- 成片不超过 5 分钟，另一台设备完整播放检查声音字幕。
