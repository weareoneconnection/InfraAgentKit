# InfraAgentKit 作品摘要

**作品名称：InfraAgentKit——交通基础设施智能体技能、工具与 MCP 开源框架**

定位：把交通行业 Agent 从“Prompt + 大模型调用”升级为可审查的软件工程体系。框架以 Agent Card 声明能力和权限，以 Tool Registry/MCP 提供标准化工具，以 Evidence Contract 约束结论，以 Human Gate 控制副作用，以 Execution Receipt 与独立 Verifier 验证执行结果。

当前包提供可安装 Python SDK、CLI、Runtime API、3 个行业 Agent 示例、Tool/Policy/Evidence/Receipt/Verifier 核心模块、治理 Benchmark、Docker 与 CI，并提供基于官方 MCP Python SDK v2 的 MCP Server 适配代码。
