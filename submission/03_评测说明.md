# 评测说明

运行：`PYTHONPATH=. python evals/run_benchmark.py`

当前治理 Benchmark 验证：
- 有证据场景必须生成 SUPPORTED Finding；无证据场景必须 GAP。
- 只有 SUPPORTED Finding 才能产生副作用 Action Intent。
- 未经人工批准的写操作无法执行。
- Execution Receipt 必须通过输入/输出摘要、工具一致性和审批一致性核验。

正式决赛建议增加 Hallucinated Tool、Invalid Evidence、Prompt Injection、Cross-Tenant Data、Replay/Idempotency、Timeout/Retry、MCP Tool Security 等测试集。
